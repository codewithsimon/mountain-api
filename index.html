API Examples

Get Mountain by ID

Retrieve detailed information about a specific mountain using its unique identifier.

{
  "id": "everest",
  "name": "Mount Everest",
  "height": 8849,
  "unit": "meters",
  "prominence": 8849,
  "range": "Himalayas",
  "country": ["Nepal", "China"],
  "coordinates": {
    "latitude": 27.9881,
    "longitude": 86.9250
  },
  "firstAscent": {
    "year": 1953,
    "climbers": ["Edmund Hillary", "Tenzing Norgay"]
  },
  "difficulty": "Extreme"
}
GET /mountains/everest

Get Started in Minutes

Three simple steps to start using Mountain API

1

Sign Up or Clone

Visit our GitHub repository or sign up for a free API key to get started.

2

Get Your API Key

Receive your unique API key instantly. No credit card required for the free tier.

3

Start Making Requests

Use your favorite programming language to start fetching mountain data.

Using cURL

curl -X GET "https://api.mountain.dev/mountains/everest" \
     -H "Authorization: Bearer YOUR_API_KEY"

Using JavaScript (Fetch API)

fetch('https://api.mountain.dev/mountains/everest', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
})
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));
